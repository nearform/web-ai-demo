Reality-check spikes

One throwaway page per runtime, no shared abstraction, latest version of each library. Models follow one policy across the repo — Gemma 4 where the runtime can run it, never Gemma 3 or earlier, the latest Qwen with a browser-sized variant, and at least one model small enough for a phone. Each page answers one question: does it load and emit tokens, on this device, today. Nothing here is the demo — the demo is built from what these find out.

Runtimes
  • web-llm

    MLC-compiled models over WebGPU. OpenAI-shaped API. Wired up — 0.2.84, catalog read at runtime.

  • wllama

    llama.cpp in WASM. Loads Hugging Face GGUFs directly. Wired up — 3.6.0, WebGPU on by default.

  • Chrome Prompt API

    Built-in model, no download in our page. Chrome only. Wired up — the session keeps its own history, so this is the only one where we don't resend it.

  • Transformers.js

    ONNX Runtime Web. Broadest model selection. Wired up — 4.2.0, dtype q4; q4f16 silently generates nothing on WebGPU.

  • LiteRT-LM

    Google's on-device runtime. Newest of the five. Not wired up yet.
